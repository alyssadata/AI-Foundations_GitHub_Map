# Definitions

This folder holds repositories that define the words, distinctions, and named concepts used in AI Foundations.

Definitions matter because they draw the boundary around terminology. They make it possible to tell when two repositories are talking about the same thing, when a term has changed meaning, and when an outside interpretation has crossed the framework's stated boundary.

A definition repository does not have to define only one word. It belongs here when its primary function is to establish, distinguish, or stabilize meaning.

Repositories may also be cross-listed in another folder when they have more than one function.
