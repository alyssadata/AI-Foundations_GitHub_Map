# Evaluations and Tests

This folder holds repositories that test whether an AI system preserves, loses, changes, substitutes, or otherwise behaves in relation to an AI Foundations construct.

Evaluations matter because they separate a stated framework claim from an observable system-behavior question. A definition says what a construct means; an evaluation specifies what is being tested and records what happened under a defined condition.

This folder includes evaluations, tests, metrics, benchmarks, and harnesses. A repository may also appear in Definitions or Protocols when it performs more than one function.
