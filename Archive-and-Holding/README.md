# Archive and Holding

This folder holds repositories that are either waiting for final placement or preserved primarily for historical, provenance, supersession, or development-record purposes.

**Holding** means the repository is real and relevant but its current category or status is unresolved.

**Archive** means the repository remains part of the public record but is not a current primary entrance or current preferred framing.

Archive does not erase authorship, provenance, or source-line. Moving a repository here is an administrative placement decision, not a claim that the repository was false.
