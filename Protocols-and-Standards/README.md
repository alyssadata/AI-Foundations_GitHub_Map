# Protocols and Standards

This folder holds repositories that specify how AI Foundations work is to be carried out, interpreted, documented, evaluated, cited, or handled under defined conditions.

Protocols matter because they make procedures repeatable. Standards matter because they set the minimum structure or rule a repository, evaluation, source reference, or interaction must satisfy.

A protocol is different from a definition: a definition establishes meaning; a protocol establishes procedure. A standard establishes the required form, boundary, or minimum condition for that procedure or artifact.
