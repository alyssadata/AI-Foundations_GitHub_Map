## Purpose

This repository is a navigational map of AI Foundations repositories.

The root README is intentionally short. Repository links are organized inside category folders so definitions, evaluations, protocols, governance, architecture, research, publications, and historical material do not collapse into one long index.

A map is administrative. Placement in this map does not itself create, remove, or alter canon status.

Repositories may appear in more than one category when they serve more than one function.

## Folder Rule

Each category folder contains:

- `README.md` — what the category means and why it exists.
- `LINKS.md` — the repositories currently mapped to that category.

The category description controls the meaning of the folder. The link page is the navigational index.
